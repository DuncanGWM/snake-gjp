# Snake GJP

A simple browser-based Snake game made with vanilla HTML, CSS, and JavaScript.

## Files

- `index.html` – page structure and HUD.
- `styles.css` – game layout and styling, including the SVG background image for the canvas.
- `game.js` – snake game logic (movement, input, scoring, collision, restart).
- `assets/gjp-bg.svg` – stylized GJP background.

## Run locally

From this project directory, start a local static server:

```bash
python3 -m http.server 8000
```

Then open:

- `http://localhost:8000`

> Use Arrow keys or WASD to control the snake.
